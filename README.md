Entry for [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) on make.fun.

`main.ts` (Node 22, no dependencies) writes exactly one letter, A to Z, and
nothing else, to `/output/entry.txt`. The letter stands for the word that
describes the day.

Run it with:

```sh
node main.ts
```
